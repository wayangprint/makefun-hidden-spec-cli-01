mend applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON tool calls — to a tree of files, to one specification. It finds the lines an edit names even when line numbers drifted, and changes every file or none.
Run: `node main.ts [patch]`
